Política de privacidad

Última actualización: 23 de octubre de 2026

CanalIA métricas es una herramienta personal que usa el dueño del canal de YouTube Tú Estuviste Ahí para leer las estadísticas de su propio canal. No es un servicio para el público: no tiene usuarios registrados ni recoge datos de otras personas.

Qué datos lee

Con permiso de solo lectura, y solo después de que el dueño del canal lo autorice con su cuenta de Google, la herramienta lee mediante los Servicios de API de YouTube (YouTube Data API y YouTube Analytics API):

  • Datos públicos del canal y de sus videos: título, fecha de publicación, duración.
  • Estadísticas del canal: vistas, tiempo de reproducción, suscriptores ganados y perdidos, "me gusta", comentarios, veces compartido, retención, fuentes de tráfico y países.

No lee correos, contactos, archivos ni ningún otro dato de la cuenta de Google. No puede publicar, editar ni borrar nada.

Para qué se usan

Solo para generar informes de rendimiento del propio canal (por ejemplo, un resumen semanal) que consulta su dueño.

Dónde se guardan

Los datos y los informes se guardan únicamente en el ordenador del dueño del canal. La autorización de Google (el token de acceso) también se guarda solo en ese ordenador. No hay servidores propios ni bases de datos en internet.

Con quién se comparten

Con nadie. Los datos no se venden, no se ceden a terceros y no se usan para publicidad.

Uso limitado

El uso y la transferencia de la información recibida de las API de Google cumplen la Política de Datos del Usuario de los Servicios de las API de Google, incluidos los requisitos de Uso Limitado.

YouTube y Google

Esta herramienta usa los Servicios de API de YouTube. Al autorizarla aceptas las Condiciones del Servicio de YouTube. El tratamiento de datos por parte de Google se rige por la Política de Privacidad de Google.

Cómo retirar el permiso

Se puede revocar el acceso en cualquier momento desde la página de permisos de tu cuenta de Google o desde la configuración de seguridad de Google. Al revocarlo, la herramienta deja de poder leer datos; los informes ya guardados se pueden borrar del ordenador en cualquier momento.
